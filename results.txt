Who won the game between the Seahawks and Rams?

SQL Syntax Response:
SELECT 
    CASE 
        WHEN g.home_team_score > g.away_team_score THEN ht.team_name
        ELSE at.team_name
    END AS winner
FROM 
    game g
JOIN 
    team ht ON g.home_team_id = ht.team_id
JOIN 
    team at ON g.away_team_id = at.team_id
WHERE 
    (ht.team_name = 'Seahawks' AND at.team_name = 'Rams')

Question:
Which team scored the most points?

SQL Syntax Response:
SELECT t.team_name, 
       SUM(CASE WHEN g.home_team_id = t.team_id THEN g.home_team_score ELSE g.away_team_score END) AS total_points
FROM game g
